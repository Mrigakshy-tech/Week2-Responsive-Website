# NOVA — Responsive Landing Page

## Project title
NOVA – Creative Digital Agency Landing Page

## Task description
This project is a responsive landing page built as part of the Week 2 Responsive Layout Project. It demonstrates how to create a clean, mobile-friendly landing page using semantic HTML, CSS Flexbox, CSS Grid, and JavaScript.

## Technologies and tools used
- HTML5 for semantic page structure
- CSS3 for styling, Flexbox, CSS Grid, fluid typography, and responsive media queries
- Vanilla JavaScript for the mobile navigation menu and dynamic footer year
- Google Fonts (DM Sans and Manrope)

## Project features
- Sticky navigation bar with a responsive mobile menu
- Hero section with call-to-action links and CSS-generated artwork
- Client/partner strip
- Three-column services grid that stacks on smaller screens
- Selected work/project showcase
- About section with responsive statistics
- Insights section and contact call-to-action
- Footer with navigation links
- Mobile-first responsive breakpoints for 360px, 680px, 900px and larger screens
- Accessible navigation labels, semantic landmarks, and keyboard-friendly links/buttons
- No external JavaScript libraries or build tools required

## Installation requirements
- A modern web browser (Chrome, Edge, Firefox, or Safari)
- A code editor such as Visual Studio Code (optional)
- Internet connection only for loading Google Fonts; system sans-serif fallbacks are provided

No package installation or `requirements.txt` is needed.

## Steps to run the project
1. Extract the ZIP file.
2. Open `Source_Code/index.html` in a browser.
3. For local development, open the project folder in Visual Studio Code and use the Live Server extension (optional).
4. Resize the browser or use Developer Tools device emulation to test the responsive layout.

## Output description
The completed output is a responsive digital agency landing page titled NOVA. The design uses a light neutral background, deep green-black typography, purple accents, and lime highlights. CSS Grid structures the hero, services, projects, and content sections; Flexbox aligns navigation, buttons, metadata, and footer elements. The mobile navigation collapses into a toggle menu on narrow screens.

## Responsive testing checklist
- [ ] 360px mobile width
- [ ] 768px tablet width
- [ ] 1280px desktop width
- [ ] Mobile menu opens and closes
- [ ] Navigation links scroll to the correct sections
- [ ] No horizontal overflow
- [ ] Text and buttons remain readable and tappable
